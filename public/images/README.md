# Image assets

Drop the real Rafting Club Armenia photographs here using **exactly these
filenames**. Until a file exists, the site shows a branded gradient placeholder
in its place (no broken layout), so you can add photos incrementally.

Guidelines:
- Use `.jpg` (or `.webp`) optimised for web (compress before uploading).
- Hero: landscape, high quality (~1920–2400px wide). It loads with priority.
- Gallery/tours: ~1200–1600px is plenty.
- Filenames are already SEO-friendly (keywords + location). Keep them.
- `alt` text is set in `content/en.ts`, `content/hy.ts`, `content/ru.ts`.
